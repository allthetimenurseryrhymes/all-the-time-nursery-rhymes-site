Privacy Policy

Last updated: 17 October 2026

This Privacy Policy explains how the All The Time Nursery Rhymes publishing app accesses, uses, stores and shares Google user data.

What the app is

The app is a private production tool operated by the owner of the All The Time Nursery Rhymes YouTube channel. It is used to automate authorised uploads and related publishing tasks for that channel. It is not offered as a public account or sign-in service.

Google user data accessed

The app requests OAuth access to the YouTube Data API using the youtube.upload scope. This permission allows the app to upload videos to the authorised YouTube channel. The app does not request access to Gmail, Google Drive, contacts, calendars or unrelated Google account data.

How Google user data is used

Google user data is used only to perform the YouTube publishing functions authorised by the account owner, including obtaining access tokens and uploading videos to the authorised channel. The app does not use Google user data for advertising, profiling, data brokerage or unrelated purposes.

Storage and security

OAuth credentials and refresh tokens used by the automated publishing workflow are stored as protected repository secrets in GitHub Actions rather than in public source code. Access is limited to the private production workflow and authorised repository access.

Sharing of Google user data

The app does not sell Google user data. It does not share Google user data with advertisers or data brokers. Data may be processed by service providers strictly as required to operate the workflow, such as Google/YouTube for API access and GitHub Actions for automation.

Retention

OAuth credentials are retained only while required to operate the authorised publishing workflow. They may be replaced, revoked or deleted by the channel owner at any time.

Revoking access

The Google account owner can revoke the app’s access at any time through the Google Account permissions page. Revoking access prevents the app from obtaining new access tokens and continuing authorised API operations.

Changes to this policy

This policy may be updated if the app’s functionality or data practices change. The current version will remain available on this website.

Contact

For privacy questions, contact allthetimenurseryrhymes@gmail.com.
